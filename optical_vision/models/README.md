# Models

This folder contains components related to `models` for the `optical_vision` module.

This folder will contain optical vision model definitions such as ViT/CNN encoders and related modules.

**What belongs here**:
- Source code, scripts, or configurations specific to models.

**What should NOT be stored here**:
- Large datasets.
- Model weights or large checkpoint files.
- Compiled binaries.
